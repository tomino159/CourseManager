# CourseManager

Mini C# console app: course and student manager (learning project).

## Features

- Manage a list of courses
- Each course has:
  - Name
  - Maximum capacity
  - List of students
- Add new courses
- Add students to selected course (with capacity check)
- List all courses with their students

## Tech

- C# console application
- Classes, constructors, methods
- Properties (`get; set;`)
- `List<T>` collections
- Loops, conditions, simple menu in `while` loop

## Purpose

This is a learning project created while practicing C# basics:
object-oriented programming, collections and console interaction.
